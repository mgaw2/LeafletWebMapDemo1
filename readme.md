# GIST 5330 Assignment 4: Leaflet Web Maps
## Matthew Gaw

This assignment uses Leaflet to display weather and earthquake data on two separate maps.

## Weather map
The weather map displays precipitation radar from the Iowa Environmental Mesonet and active National Weather Service alerts. An Esri light gray basemap helps the weather layers stand out. Extreme alerts are purple, severe alerts are red, minor alerts are green, and other alerts are orange. 

<https://mgaw2.github.io/LeafletWebMapDemo1/Weather/>

## Earthquake map
The earthquake map displays the USGS past-day feed on an OpenStreetMap basemap. Each event has a circle marker with a popup showing magnitude, location, and time in UTC. Colors show magnitude ranges, and a legend explains those colors. 

<https://mgaw2.github.io/LeafletWebMapDemo1/Earthquake/>
